## 0. 먼저 알아두실 것 — 이 홈페이지가 굴러가는 원리

이 사이트는 **글자와 사진 목록을 구글시트에서 읽어옵니다.**

```
   구글시트  ──(자동으로 읽어감)──▶  홈페이지
   (사장님이 고침)                    (1~2분 뒤 반영)
```

즉 **웬만한 수정은 구글시트만 고치면 끝납니다.** 개발자를 부르실 필요가 없습니다.

시트에는 탭이 5개 있고, 각각 홈페이지의 다른 부분을 담당합니다.

| 시트 탭 | 홈페이지에서 바뀌는 곳 |
|---|---|
| **담당자** | 맨 아래 "문의" 섹션의 담당자 카드 |
| **납품실적** | "납품실적" 섹션의 회사 목록 |
| **납품사례** | "갤러리" 섹션의 사진 카드 + 3D 비교 슬라이더 |
| **링크폼** | 견적 의뢰 / A/S 접수 / 카탈로그 버튼의 연결 주소 |
| **문구** | 각 섹션의 제목 문장 |

> ⚠️ **시트를 고쳐도 홈페이지가 안 바뀌면** — 브라우저에서 새로고침을 세게 해보세요.
> (`Ctrl` + `F5`) 그래도 안 되면 1~2분 기다렸다 다시 보세요.

## 2. 납품사례(갤러리) 사진 추가 · 교체

### 2-1. 사진 없이 목록만 바꾸기
**시트 `납품사례` 탭**에서 제목·설명·순서를 고치면 즉시 반영됩니다.

- **`노출(Y/N)`** — `N`으로 바꾸면 그 사례가 홈페이지에서 **사라집니다.** 줄을 지울 필요 없습니다.
  잠깐 내렸다가 나중에 다시 올리고 싶을 때 유용합니다.
- **`표시순서`** — 작은 숫자가 앞에 나옵니다.
- **`추가사진`** — 사진을 클릭했을 때 뜨는 팝업에서 여러 장을 넘겨볼 수 있게 합니다.
  파일명을 쉼표로 구분해 여러 개 적으면 됩니다.

### 2-2. 새 사진을 올리기 (2단계)

**1단계 — GitHub `images` 폴더에 사진 파일을 올립니다.**
(전에 "Add files via upload" 하시던 그 방식입니다.)

**2단계 — 시트 `납품사례` 탭의 `사진파일명` 칸에 파일명을 적습니다.**

파일명 규칙 — **이것만 지키시면 됩니다:**
- **영문 소문자 + 숫자 + 밑줄(`_`)만** 사용. 예: `case_seoul_office.jpg`
- **한글·공백·괄호를 쓰면 사진이 안 뜹니다.** (`서울 사옥(1).jpg` ❌)
- 가로 1600px 내외 JPG 권장. 휴대폰 사진 그대로도 괜찮습니다.

## 3. ⭐ 3D 설계안 → 실제 시공 슬라이더 (앞으로 쌓아나갈 것)

왼쪽에 3D 설계 렌더링, 오른쪽에 실제 완공 사진을 놓고 **손으로 밀어 비교**하는 기능입니다.
지어낸 이미지가 하나도 없어 문제 소지가 없고, "설계한 대로 지었다"는 메시지에
설계 역량까지 같이 보여줍니다.

### 3-1. 추가하는 방법 (3단계)

**1단계 — 사진 2장 준비**

| 위치 | 무엇 | 파일명 예시 |
|---|---|---|
| 왼쪽 | 그 현장의 **3D 설계 렌더링** | `case_yongin_3d.jpg` |
| 오른쪽 | **같은 공간**의 실제 완공 사진 | `case_yongin_after.jpg` |

> **핵심은 "같은 공간, 비슷한 각도"입니다.** 두 장을 겹쳐놓고 미는 방식이라
> 다른 방이거나 각도가 크게 다르면 효과가 없습니다.
> 두 장의 가로세로 비율이 같으면 가장 깔끔합니다.

**2단계 — GitHub `images` 폴더에 2장 다 올립니다.**

**3단계 — 시트 `납품사례` 탭에 줄을 추가하고, 맨 오른쪽 `설계3D` 칸에 3D 파일명을 씁니다.**

| 제목 | 카테고리 | 한줄설명 | 사진파일명 | 표시순서 | 노출 | 추가사진 | **설계3D** |
|---|---|---|---|---|---|---|---|
| 용인 사옥 라운지 | 오피스 | 3D 설계안대로 시공 완료 | `case_yongin_after.jpg` | 10 | Y | | **`case_yongin_3d.jpg`** |

- `사진파일명` = **완공 사진** (오른쪽)
- `설계3D` = **3D 렌더링** (왼쪽)

**저장하면 1~2분 안에 슬라이더가 자동으로 생깁니다.**

### 3-2. 동작 규칙

- `설계3D` 칸이 **비어 있으면** → 그 사례는 슬라이더 없이 기존 갤러리 사진으로만 나옵니다.
  → **기존 사례들은 아무것도 안 하셔도 그대로입니다.**
- `설계3D`가 채워진 사례가 **하나도 없으면** → 슬라이더 섹션이 통째로 사라집니다. 빈 껍데기가 안 남습니다.
- 여러 개 채우면 **채운 만큼 슬라이더가 늘어납니다.**
- 파일명을 잘못 적어 사진이 없으면 → 깨진 아이콘 대신 **그 칸만 조용히 사라집니다.** 화면이 망가지지 않습니다.

### 3-3. 앞으로 현장에서 챙기실 것 — 딱 2가지

1. **설계팀의 3D 렌더링 이미지 파일**
   - 제안서에 넣었던 그 이미지면 충분합니다. **새로 만들 필요 없습니다.**
   - 어느 공간을 그린 건지 파일명이나 메모로 남겨두세요. 나중에 짝 맞추기가 쉬워집니다.
2. **완공 후 그 3D와 같은 각도에서 찍은 사진 한 장**
   - 준공 사진 찍으실 때 **"3D 뽑았던 각도에서 한 장 더"** 만 요청하시면 됩니다.
   - **이게 이 기능의 성패를 가릅니다.** 각도만 맞으면 나머지는 전부 자동입니다.

> 💡 지나간 현장도 됩니다. 제안서·월례회의 자료 PDF에 3D 이미지가 들어 있는 경우가 많습니다.
> 실제로 지금 등록된 라운지 세트가 그렇게 만들어졌습니다.

### 3-4. 현재 등록 현황

| 사례 | 3D 설계안 | 완공 사진 | 출처 |
|---|---|---|---|
| 기업 사옥 라운지 · 팬트리 | `case_pantry_3d.jpg` | `case_pantry_after.jpg` | 월례회의 자료.pdf |

**확인 대기 1건** — 서가형 스터디 라운지. 제안서 3D와 완공 사진이 둘 다 있으나
서가 위치·바닥재가 달라 **같은 공간인지 확인이 필요합니다.** 현장을 아시면 판단해 주세요.

## 4. 버튼 연결 주소 바꾸기 (견적폼 · A/S · 카탈로그)

**시트 `링크폼` 탭**에서 주소만 갈아끼우면 됩니다.

| 항목 | URL |
|---|---|
| 전화 대표 | `tel:02-2185-2263` |
| 견적 의뢰 폼 | https://forms.gle/... |
| A/S 접수 폼 | https://forms.gle/... |
| 카탈로그 | https://docs.google.com/forms/... |

- **`항목` 이름은 바꾸지 마세요.** 홈페이지가 이 이름으로 찾아갑니다.
  (`카탈로그`를 `카달로그`로 고치면 카탈로그 버튼이 사라집니다.)
- 전화번호는 반드시 **`tel:`** 로 시작해야 휴대폰에서 바로 걸립니다.

## 5. 섹션 제목 문구 바꾸기

**시트 `문구` 탭**에서 `내용` 칸만 고치세요.

- **`키` 이름은 절대 바꾸지 마세요.** 홈페이지가 이 이름으로 찾아갑니다.
- 줄바꿈은 칸 안에서 **`Alt` + `Enter`** — 홈페이지에도 그대로 줄이 나뉩니다.
- 단어를 **`**별표 두 개**`** 로 감싸면 그 단어만 **강조색**으로 나옵니다.
  예: `사옥 전체까지, **에넥스.**`

## 6. 자주 겪는 문제 (고장 아닙니다)

| 증상 | 원인과 해결 |
|---|---|
| 시트를 고쳤는데 홈페이지가 그대로 | 1~2분 기다린 뒤 `Ctrl`+`F5` 로 새로고침 |
| 사진이 안 뜨고 빈칸 | 파일명에 **한글·공백**이 있거나, GitHub `images` 폴더에 안 올라간 경우. 파일명 오타(대소문자도 구분) 확인 |
| 카탈로그 버튼이 사라짐 | `링크폼` 탭의 항목 이름이 정확히 **`카탈로그`** 인지 확인 |
| 담당자가 한 명만 나옴 | `표시순서` 칸이 비어 있는지 확인 |
| 갤러리에서 특정 사례를 빼고 싶음 | 줄을 지우지 말고 `노출` 칸을 **`N`** 으로 |
