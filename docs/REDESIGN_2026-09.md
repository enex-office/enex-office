# 에넥스 오피스 홍보 사이트 — 전면 개편안 (2026-09)

작성: 2026-09-02 · 상태: **시안 (승인 전)** · 샘플 파일: 저장소 루트 `preview.html`

> 이 문서는 "페이지가 정적이고 단순해 보인다 → 움직이는 이미지·영상을 결합하고 싶다"는 요청에 대한 개편 제안입니다.
> 실제 사이트(`index.html`)는 아직 **하나도 바뀌지 않았습니다.** 승인 후 교체합니다.

## 1. 진단 — 지금 페이지가 "정적"으로 보이는 이유

| 항목 | 현재 | 문제 |
|---|---|---|
| 커버 | 사진 1장 + 22초 느린 줌 | 첫 3초에 눈에 띄는 변화가 거의 없음 |
| 섹션 구조 | 11개 섹션이 전부 "흰 카드 나열" | 어느 섹션을 봐도 같은 모양 → 스크롤해도 장면이 안 바뀜 |
| 사진 사용 | 인프라 2장·제품 4장·갤러리 | 사진이 카드 안에 작게 갇혀 있음. 회사 강점(공장·시공 현장)이 화면을 채우는 순간이 없음 |
| 움직임 | 카드 순차 등장, 숫자 카운트 | 있지만 "카드가 살짝 뜨는" 정도라 체감이 약함 |
| 배경 리듬 | 크림 ↔ 샌드 교차 | 명도 차이가 작아 섹션 경계가 흐릿함 |

접속 경로가 **명함 QR → 휴대폰**이라는 점이 핵심입니다. 구매·품의 담당자가 엘리베이터에서 10초 보는 페이지라면,
첫 화면에서 "회사가 살아 움직인다"는 인상을 주고, 스크롤할 때 장면이 바뀌어야 합니다.

## 2. 개편 방향 (3줄)

1. **사진을 크게, 화면 가득** — 공장·시공 현장·제품 사진을 카드에서 꺼내 풀블리드(가로 꽉 채움)로 씁니다.
2. **밝은 장면 ↔ 어두운 장면 교차** — 커버(어둠) → 소개(밝음) → 인프라(어둠) → … → 문의(어둠). 스크롤마다 장면이 바뀝니다.
3. **움직임은 "내용을 설명하는 것"만** — 물류 거점이 선으로 이어지고, 진행 절차 선이 채워지고, 인증 배지 원이 그려지는 식. 장식용 애니메이션은 넣지 않습니다.

## 3. 그대로 유지하는 것 (건드리지 않음)

- 구글시트 5개 탭(담당자·납품실적·납품사례·링크·문구) 연동 구조와 주소, `FALLBACK` 안전망, CSV 파서
- 문구 시트 키(`커버_제목`, `회사_제목` … 12개) — 시트에서 문구 관리하는 방식 그대로
- 순수 HTML/CSS/JS **한 파일**, 프레임워크·빌드 도구 없음, GitHub Pages 그대로 배포
- Paperlogy 단일 폰트, 버건디(`--brick`) 중심 색상 체계
- 섹션 11개와 순서, 모바일 하단 전화바, 갤러리 팝업(라이트박스), 인쇄용 CSS
- 마퀴(티커)·스크롤 스냅은 **재도입하지 않음** (과거 제거 사유 유지)

## 5. 움직임 설계 원칙

- **무겁지 않게**: 새로 추가된 움직임은 전부 CSS transition/animation 또는 가벼운 스크롤 계산 1개. 외부 라이브러리 0개.
- **한 번만**: 등장 애니메이션은 섹션당 1회. 반복되는 건 커버 슬라이드쇼·스크롤 힌트·공장 점 맥박 3개뿐.
- **"동작 줄이기" 설정 대응**: 휴대폰/PC에서 동작 줄이기(prefers-reduced-motion)를 켠 사용자에게는 모든 움직임을 끄고 정지 화면으로 표시. 영상도 로드하지 않음.
- **데이터 절약 모드**(Android Data Saver)에서는 영상을 받지 않고 사진 슬라이드쇼만.
- **JS가 꺼져도 백지 없음**: 등장 애니메이션은 JS가 있을 때만 "숨김→표시"로 동작. 없으면 그냥 다 보임.

## 6. 영상 계획 — 세 가지 선택지

| 방식 | 비용 | 준비물 | 효과 | 권장 |
|---|---|---|---|---|
| **A. 사진 슬라이드쇼**(이미 구현) | 0원 | 기존 사진 | 정지 화면 대비 확실히 "살아 있음". 영상보다 데이터 가벼움 | ✅ 즉시 적용 가능 |
| **B. 비포/애프터 비교 슬라이더**(이미 구현) | 0원 | **시공 전 현장 사진**만 추가 촬영 | "옛 사무실 → 새 가구" 변화를 사용자가 직접 밀어보며 체감. AI 영상의 목적을 가장 정직하게 달성 | ✅ 다음 시공 현장부터 사진 확보 권장 |
| **C. 커버 영상**(슬롯 구현, 파일 없음) | AI 생성 시 Higgsfield Starter $19/월~ 또는 실촬영 | mp4 파일 1개 | 가장 화려하지만 데이터·배터리 부담, AI 영상은 "우리 현장"이 아님 | ⏸ 파일 확보 후 결정 |

**영상 파일 규격(C 선택 시)**: mp4(H.264), 1280×720, 10~15초 무음 루프, **6MB 이하**.
저장소 `video/hero.mp4`로 올리고 시트 `links` 탭에 항목 `커버영상` / URL `video/hero.mp4` 한 줄을 추가하면 자동 적용됩니다(코드 수정 불필요).
파일이 없거나 로드 실패 시 자동으로 사진 슬라이드쇼로 돌아갑니다.

## 6-1. '시공 전' 사진을 AI로 만드는 건에 대해 (2026-09-02 요청)

- 이 작업 환경(Claude Code)에는 **이미지 생성 기능이 없습니다.** 모델을 바꿔도 같습니다. 만들려면 외부 이미지 AI(Higgsfield·Midjourney·포토샵 생성형 채우기 등)에서 만들어 파일로 주셔야 합니다.
- 우려 한 가지: 실제 고객사 현장의 **가짜 '시공 전' 사진을 진짜처럼** 구매담당자에게 보여주는 건 표시·광고 리스크가 있고, 들킬 경우 신뢰 손실이 큽니다. 쓰시려면 "연출 이미지" 표기를 권합니다.
- 대신 지금 구현한 것: **완공 사진에서 선만 뽑은 스케치 ↔ 완공 사진** 슬라이더. 같은 공간을 그린 것이라 거짓이 없고, "구상 → 실제" 서사가 자연스럽습니다. 시안 §8 하단에 3세트(회의실·업무공간·라운지) 적용.
- 진짜 시공 전 사진이 생기면 시트 `비포사진` 열로 BEFORE/AFTER 슬라이더가 사례 카드에 자동 적용됩니다(§7).

## 7. 비포/애프터 슬라이더 — 시트 연결 방법

- `cases`(납품사례) 탭에 **`비포사진`** 열을 추가(선택 사항). 파일명(예: `case_office_w_before.jpg`)을 넣은 행만 카드가 슬라이더로 바뀝니다.
- 열이 없거나 비어 있으면 지금처럼 일반 사진 카드. **기존 데이터·기존 열에 영향 없음.**
- 샘플 페이지 하단의 데모 블록은 동작 확인용(두 장 모두 시공 후 사진)이며, 실제 비포 사진이 준비되면 데모 블록은 삭제합니다.

## 8. 확인 방법

1. **샘플 페이지**: 채팅으로 전달된 Artifact 링크(휴대폰으로도 열림). 이 미리보기는 보안상 구글시트를 불러오지 못해 `FALLBACK` 데이터(현재 시트와 같은 내용)로 표시됩니다 — 실제 배포 시엔 시트 데이터가 그대로 들어옵니다.
2. **로컬**: 저장소에서 `python -m http.server 8080` → `http://localhost:8080/preview.html`
3. **점검 완료 항목**: JS 문법(`node --check`) 통과 · 이미지/폰트 경로 일치 · 380px/1920px 가로 스크롤 없음 · 시트 연결 실패 시 FALLBACK 정상 표시

## 9. 결정이 필요한 사항

### 이미 결정된 것 (반영 완료)
- ✅ 커버 사진 슬라이드쇼 — 확정("아주 좋다")
- ✅ PC 상단 고정 내비 — 제거 (스크롤 중 사진 윗부분을 계속 가림)
- ✅ 갤러리 첫 카드 2칸 확대 — 제거 (옆에 빈 칸처럼 보임)
- ✅ 사업영역 타일 — 글자가 사진과 겹쳐 안 읽힘 → 사진(위) / 어두운 글 판(아래) 분리
- ✅ 인프라 거점 — 가로 타임라인("단계가 많다"는 인상) → 황간 중심 방사형 지도 + "7거점 동시 출고"
- ✅ 서울 본사 지도에 표시(부제 HEAD OFFICE) + 안성과 묶어 점선 "수도권" 영역. 오른쪽 수도권 설명 문단은 삭제
- ✅ A-4: 기숙사·카페테리아 사례는 사진 확보 전까지 화면에서 제외
- ✅ C: 월례회의 PDF의 완공 사진 3장으로 **스케치 → 완공** 슬라이더 구현 (AI 생성 '시공 전' 사진은 이 환경에서 불가 + 표시광고 리스크 → §6-1 참조)

### A. 시트 데이터 확인 — 사장님만 하실 수 있는 것 (가장 중요)
> 이 환경은 보안상 구글시트 접근이 막혀 있어(EGRESS_BLOCKED) 제가 직접 못 봅니다.

- **A-1. `담당자` 탭 현재 내용** — 조인진 차장님 포함 전체 행. 내장 백업값이 이종민·김지민 2명뿐이라 시트가 안 열리는 순간 실사이트에도 2명만 나옴
- **A-2. `링크` 탭 현재 내용** — 특히 **카탈로그 URL**. 백업값에 카탈로그 행이 없어서, 시트가 안 열리면 카탈로그 배너가 통째로 사라짐
- **A-3. `납품사례` 탭 `사진파일명` 열이 실제 사진과 맞는지** — 저장소 파일 실물 확인 결과 이름과 내용이 어긋나 있음:

- **B-1. 개편안 전체 방향** (밝은/어두운 화면 교차 + 큰 사진) — 진행 / 일부만 / 보류
